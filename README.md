# Shop Stock Manager

A clean, lightweight, and responsive Shop Stock management web application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Inventory Tracking**: Add stock items with item name, price, and units left.
- **Persistent Storage**: Uses browser `localStorage` so data stays after refreshing or closing the page.
- **Search**: Real-time search filter to quickly find any item.
- **Live Counters**: Displays total distinct items and total units in stock at the top.
- **Edit & Delete**: Full editing capabilities and safe deletion with confirmation.
- **Responsive & Mobile-Ready**: Clean UI optimized for both phone screens and desktop browsers.

## Project Structure

```text
├── index.html   # Main layout and semantic structure
├── style.css    # Clean modern styles and responsive design
├── script.js    # State management, validation, and localStorage operations
└── README.md    # Documentation
```

## Getting Started

No dependencies, backend, or build step required. Simply open `index.html` in any modern web browser.
